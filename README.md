# CertifyPro - Piattaforma Certificati Digitali

Crea, personalizza e invia certificati digitali professionali ai tuoi studenti con condivisione LinkedIn integrata.

## Funzionalita'

- **Dashboard** - Panoramica completa con statistiche in tempo reale e azioni rapide
- **6 Template Professionali** - Elegante Classico, Moderno Minimal, Royal Premium, Tech & Innovation, Nature & Growth, Gradient Bold
- **Designer Live** - Personalizzazione completa del certificato con anteprima in tempo reale (titolo, corso, colori, firma, QR code)
- **Gestione Destinatari** - Aggiunta manuale e importazione CSV con drag & drop, ricerca e selezione multipla
- **Invio Email Personalizzate** - Template email con placeholder dinamici ({nome}, {corso}) e pulsante "Condividi su LinkedIn"
- **Integrazione LinkedIn** - Condivisione diretta sul feed e aggiunta alla sezione Certificazioni del profilo
- **Storico Invii** - Registro completo di tutti i certificati emessi con esportazione CSV
- **Verifica Certificati** - ID univoci (CERT-XXXXXX) e QR code di verifica

## Utilizzo

1. Aprire `index.html` in un browser moderno
2. Scegliere un template dalla galleria o creare un design personalizzato
3. Aggiungere i destinatari manualmente o importare un file CSV (formato: nome, email, corso, data)
4. Personalizzare il messaggio email e inviare i certificati
5. I destinatari riceveranno un'email con il certificato e il pulsante per condividerlo su LinkedIn

## Tech Stack

- HTML5, CSS3, JavaScript (Vanilla)
- SPA con routing client-side
- Persistenza dati via localStorage
- Design responsive (mobile e desktop)
- Zero dipendenze esterne

## Browser Supportati

Chrome, Firefox, Safari, Edge (versioni moderne).
