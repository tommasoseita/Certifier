# Calcolatrice Web App

Una calcolatrice semplice e responsive costruita con HTML, CSS e JavaScript.

## Funzionalità

- Operazioni base: addizione, sottrazione, moltiplicazione, divisione
- Supporto tastiera
- Design responsive (mobile e desktop)
- Gestione errori (divisione per zero)
- Formattazione numeri con separatori migliaia

## Utilizzo

1. Aprire `index.html` in un browser moderno
2. Cliccare i pulsanti o usare la tastiera:
   - `0-9`: Inserire numeri
   - `+`, `-`, `*`, `/`: Operazioni
   - `Invio` o `=`: Calcola risultato
   - `Backspace`: Cancella ultima cifra
   - `Esc`: Cancella tutto

## Browser Supportati

Chrome, Firefox, Safari, Edge (versioni moderne).
